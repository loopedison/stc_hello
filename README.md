# STC8G1K08A 示例项目

基于 STC8G1K08A 的 Keil C51 裸机程序，采用主循环轮询与中断驱动相结合的方式组织功能。

## 功能

- Timer0 提供毫秒计时及 ADC 采样触发。
- UART1 提供串口收发和交互式 Shell。
- ADC 交替采集 P5.4、P5.5，并对样本求均值。
- 按键去抖、短按、长按和双击事件处理；LED 状态指示。
- 应用状态机、事件队列、看门狗及软件重启。

## 引脚

| 功能 | 引脚 |
| --- | --- |
| LED | P3.2，低电平点亮 |
| 系统按键 | P3.3，低电平有效 |
| ADC 通道 | P5.4、P5.5 |
| PWM 示例 | P3.2（与 LED 共用引脚，勿同时启用） |

## 构建与使用

使用 Keil uVision 打开 `hello.uvproj`，选择 `hello` 目标并构建、下载。当前配置的系统时钟为 24 MHz，串口波特率为 115200。

串口连接后可使用以下 Shell 命令：

| 命令 | 说明 |
| --- | --- |
| `rst` | 延时后重启 |
| `time` | 查看运行时间 |
| `tx` / `rx` | 查看串口缓冲区状态 |
| `adc` | 查看 ADC 最近一次均值 |
| `app` | 查看应用状态 |
| `debug enter` / `debug exit` | 切换调试状态 |

源码位于 `Sources/`；Keil 构建输出位于 `Objects/` 和 `Listings/`。
